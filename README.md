# bkashjee.github.io

Personal portfolio and resume of Bikash Joshi — Software Engineer building desktop apps, web, and AI agent systems.

Live at [bkashjee.github.io](https://bkashjee.github.io/).

## Stack

Vite · React 19 · TypeScript · Tailwind CSS 4 · Motion (Framer Motion) · Lenis

## Development

```bash
npm install
npm run dev        # dev server at :5173
npm run build      # static build to dist/
npm run preview    # preview the build at :4173
npm run resume:pdf # regenerate public/resume/bikash-joshi-resume.pdf (needs preview server)
```

Deployed to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.

## Content rules

Everything on the site is real: no invented employment, follower counts, testimonials, client logos, or performance claims. Projects marked "source private" are real applications whose repositories are not public.
